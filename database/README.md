# E-commerce PostgreSQL Schema

This directory contains plain SQL migration and seed scripts for the e-commerce data model.

## Files

- `migrations/001_create_ecommerce_schema.sql` creates the database schema, constraints, foreign keys, triggers, and indexes.
- `seeds/001_seed_ecommerce_data.sql` inserts representative sample data for categories, products, variants, inventory, customers, addresses, orders, order items, payments, shipments, and reviews.

## Apply locally with psql

Set `DATABASE_URL` to your PostgreSQL connection string, then run:

```bash
psql "$DATABASE_URL" -f database/migrations/001_create_ecommerce_schema.sql
psql "$DATABASE_URL" -f database/seeds/001_seed_ecommerce_data.sql
```

## Apply in Supabase

The scripts are compatible with Supabase PostgreSQL. You can run them in order through the Supabase SQL editor or Supabase CLI.

## Schema highlights

The schema uses UUID primary keys generated by `pgcrypto`, case-insensitive customer emails through `citext`, PostgreSQL enum types for product, order, payment, and shipment states, integer-cent money columns to avoid floating-point errors, and JSONB for flexible product variant options and order address snapshots. Referential integrity is enforced with foreign keys, while check constraints validate prices, totals, inventory counts, ratings, currencies, slugs, and required text fields.

Indexes are included for common catalog, inventory, order management, and review queries, including product publication lookups, category navigation, variant option JSONB searches, low-stock inventory checks, customer order history, order status queues, payment and shipment status filters, and approved product review retrieval.
